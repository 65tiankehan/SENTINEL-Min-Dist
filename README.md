# SENTINEL MIN · Dist

本仓库只放**发布产物**，不放源码。源码在 https://github.com/65tiankehan/SENTINEL-Min 。

## 命名约定

- 资产文件名随机（`sm-<hash>.zip`），避免被按名字直接抓取；
- 每个 Release 附 `sha256`，安装器/用户下载后校验；
- tag 与版本一致：`min-0.1.0`、`min-0.1.1` …
